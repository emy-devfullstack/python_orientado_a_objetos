# Exercícios de Programação Orientada a Objetos com Python

Este README reúne exercícios do curso de **Programação Orientada a Objetos com Python da Alura**.

O objetivo é praticar a criação de classes, atributos, métodos construtores, instanciamento de objetos e métodos especiais em Python.

As respostas dos exercícios estão organizadas em arquivos separados, e cada arquivo corresponde ao exercício indicado abaixo.

---

## Exercício 1

**Arquivo de resposta:** `carro.py`

Implemente uma classe chamada `Carro` com os atributos básicos:

- modelo
- cor
- ano

Depois, crie uma instância dessa classe e atribua valores aos seus atributos.

---

## Exercício 2

**Arquivo de resposta:** `restaurante.py`

Crie uma classe chamada `Restaurante` com os seguintes atributos:

- nome
- categoria
- ativo

Além desses, crie mais 2 atributos de sua escolha.

Depois, instancie um restaurante e atribua valores aos seus atributos.

---

## Exercício 3

**Arquivo de resposta:** `restaurante_1.py`

Modifique a classe `Restaurante` adicionando um método construtor que aceita `nome` e `categoria` como parâmetros.

O atributo `ativo` deve iniciar como `False` por padrão.

Depois, crie uma instância utilizando o construtor.

---

## Exercício 4

**Arquivo de resposta:** `restaurante_2.py`

Adicione um método especial `__str__` à classe `Restaurante`.

Ao imprimir uma instância da classe, deve ser exibida uma mensagem formatada contendo o nome e a categoria do restaurante.

Depois, exiba essa mensagem para uma instância de restaurante.

---

## Exercício 5

**Arquivo de resposta:** `cliente.py`

Crie uma classe chamada `Cliente` e defina 4 atributos para ela.

Depois, instancie 3 objetos dessa classe e atribua valores aos seus atributos utilizando um método construtor.
